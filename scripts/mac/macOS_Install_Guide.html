macOS Installation & Security

The Klang Farmer & The Klang Planter

Universal Binaries for Apple Silicon (M1/M2/M3/M4) & Intel x86_64

1. Automatic .pkg Installer (Recommended)

The standard macOS .pkg installer is the fastest, zero-friction install method:

  1. Double-click TheKlangFarmer-vX.X.X-macOS-Installer.pkg.
  2. Follow the on-screen installer prompts and authorize with your macOS administrator password or Touch ID.
  3. The installer automatically installs all VST3, AU, and Standalone components and runs a built-in post-install script that automatically removes Gatekeeper quarantine flags.
  4. Restart your DAW (Logic Pro, Ableton Live, Reaper, FL Studio) — the plugins will scan immediately without Gatekeeper prompts!

2. Portable .dmg (Drag & Drop)

If you prefer installing manually from the .dmg archive:

  1. Double-click the .dmg to mount the volume.
  2. Drag The Klang Farmer.vst3 and The Klang Planter.vst3 to the Drag to VST3 Folder shortcut.
  3. Drag The Klang Farmer.component and The Klang Planter.component to the Drag to AU Components Folder shortcut.
  4. Drag Standalone .app files to your Applications folder.
  5. Double-click Fix_Mac_Permissions.command to unquarantine the installed files.

3. Manual Gatekeeper Bypass (If Ever Prompted)

Because The Klang Farmer is free and open-source software distributed without a paid Apple Developer certificate, macOS Gatekeeper may occasionally display:

"The Klang Farmer.vst3 cannot be opened because Apple cannot check it for malicious software."

To authorize the plugin in 2 quick clicks:

1
Open System Settings → Privacy & Security. Scroll down to the Security section near the bottom.
2
You will see a notification stating "The Klang Farmer was blocked from use because it is not from an identified developer." Click the Open Anyway button right next to it, then confirm with your password.

Alternatively, open Terminal.app and run this single command:

sudo xattr -rd com.apple.quarantine /Library/Audio/Plug-Ins/VST3/The\ Klang* /Library/Audio/Plug-Ins/Components/The\ Klang*

4. DAW Rescan Instructions

  • Logic Pro: Settings → Plug-in Manager → Select "R'lyeh Sound" → Click Reset & Rescan Selection.
  • Ableton Live: Preferences → Plug-Ins → Hold Option and click Rescan.
  • Reaper: Preferences → Plug-ins → VST → Re-scan → Re-scan failed plug-ins.
  • FL Studio: Options → Manage Plugins → Find installed plugins with "Verify plugins" enabled.
