# Implementation Plan: v0.5.0 The Klang Hub & UI Architecture Overhaul

## Overview
This milestone establishes the finalized universal UI/UX paradigm across The Klang Suite, codenamed the "Visual Harness" architecture. It completely overhauls how users interact with modulation, view ports, themes, and right-click menus.

This plan was synthesized in Pro High via the "V-Lab" architectural interview system.

## Phase 1: The "Arcade Meter Bar" & Popover Controls
- [ ] Refactor `RotaryKnobSlider` and `DiagramSlider` to adopt the horizontal **Arcade Meter Bar** visual paradigm.
  - Implement a persistent background trough that acts as a DSP trace (e.g., drawing morphing waveforms or envelope curves directly inside the slider bounds).
- [ ] Implement **Horizontal Action-Bar Popovers** in `juce::CallOutBox`.
  - When right-clicking a control, spawn a pill-shaped popover.
  - Replace OS-style lists with horizontal layout: `[ Text Entry ] | [ ↺ Reset ] | [ 🎲 d6 Randomize ]`.

## Phase 2: The Mod Matrix Spreadsheet Tab
- [ ] Create a dedicated `ModMatrixTabComponent`.
- [ ] Remove Mod Matrix routing from the default 4-control card grid to eliminate horizontal scrolling constraints.
- [ ] Implement the **Classic Spreadsheet Grid** list layout:
  - Each row strictly contains: `Source Button` ➔ `Amount Fader (Arcade style)` ➔ `Destination Label` ➔ `Bypass Toggle`.
- [ ] Wire the list component to dynamically reflect the `ParameterManager` routing arrays.

## Phase 3: The Standalone "Klang Hub" & Theme Architecture
- [ ] Restrict the VST3 `SettingsModal` theme configuration to **Hybrid Base + Custom** (Option 1).
  - Users select a base JSON theme and can only override the `Base Background` and `Primary Accent` colors.
- [ ] Scaffold the standalone application `TheKlangHub.exe` (or `The Klang Editor Lite`).
  - Create a new JUCE standalone application target in `CMakeLists.txt`.
  - Implement the **Multi-Scale Tri-View** viewport to act as a component sandbox and guided tour.
  - Implement the **Full Custom Palette Editor** allowing developers and power-users to edit every JSON theme color variable, manage preset banks, and export `.json` theme files.
