## 🎯 Strategic Objective
Implement the complete front-end UI/UX control surface architecture, navigation shells, micro-interaction contracts, and inspection panels on The Klang Farmer. This adopts a "Shell-First" methodology: deliver fully tested, interactive, and visually stunning UI components with inert audio-thread stubs so the entire user experience is locked down before wiring complex DSP modulation backends in v0.5.0.

## 🏗️ Phase Breakdown

### Phase 1: Persistent Lower Modulator Dock Strip (`ModulatorDock`)
- **Component Design (`ModulatorDock.h/.cpp`)**:
  - Resides at the lower edge of `FarmerEditor` beneath the module cards (height ~96px, collapsible with toggle button in status bar).
  - Contains 16 uniform modulation tiles:
    - 4 LFOs (`LFO 1..4`)
    - 4 Envelopes (`ENV 1..4`)
    - 4 Performance Macros (`MACRO 1..4`)
    - 4 Chaos/Random sources (`RND 1..4`)
- **Performance & Painting Invariants**:
  - `setBufferedToImage(true)` on static tile frames, borders, and background grids.
  - Animated waveforms/meters rendered at 30 Hz via lightweight dirty-rect invalidation (`repaint(tileBounds)`).
- **Drag-and-Drop Drag Pill (`ModulationSourcePill`)**:
  - Each tile features a tactile drag handle. Dragging initiates a `juce::DragAndDropContainer` gesture with source identifier.
  - While dragging, compatible target sliders on the active page illuminate with glowing cyan target halos.
- **Z-Order Overlay Spline Layer (`ModulationOverlayLayer`)**:
  - Topmost transparent layer (`setInterceptsMouseClicks(false, false)`).
  - Renders glowing Bézier tracer splines connecting modulation sources to targets.
  - Invalidation strictly constrained to `repaint(oldBounds.getUnion(newBounds).expanded(8))` — zero full-window repainting.

### Phase 2: Alt+Click Flip Cards (`FlipCardContainer`)
- **Container Architecture (`FlipCardContainer.h/.cpp`)**:
  - Wraps existing `ModuleCard` components in the synthesizer page layout.
  - Maintains internal view state (`enum class CardState { MainParameters, ModulationDepth }`).
- **Interaction Contract**:
  - Normal Click/Drag: standard parameter manipulation.
  - `Alt + Click` (Windows) / `Option + Click` (macOS) on any parameter slider triggers a smooth horizontal 3D card flip animation or snappy crossfade to `ModulationInjectorView`.
- **Modulation Injector View (`ModulationInjectorView.h/.cpp`)**:
  - Surfaces the clicked target parameter's name and value at the top with a prominent `[↩ Back]` button.
  - Presents 4 bipolar depth sliders (`-100%` to `+100%`) representing the 4 primary modulation sources for that parameter.
  - Inactive views call `setVisible(false)` to halt painting cycles while keeping APVTS `SliderAttachment` objects intact (zero heap allocations on flip).
- **Accessibility & Contrast**:
  - Modulation indicator rings around target sliders use shape coding:
    - Solid arc: Envelope modulation.
    - Dotted arc: LFO modulation.
    - Dashed arc: Chaos/Random modulation.

### Phase 3: 3-Column Slide-Over Preset Browser (`PresetBrowserOverlay`)
- **Overlay Drawer Architecture (`PresetBrowserOverlay.h/.cpp`)**:
  - Docks to the right side of `FarmerEditor` (~520px wide) with smooth slide-in animation.
  - Backdrop dims the inactive synth rack with subtle semi-transparent dark scrim.
  - Header features search input with instant clear `✕`, bank selector, and close button `✕` (or `Escape` key shortcut).
- **Column 1: Taxonomy & Tag Filtering (Width ~130px)**:
  - Scrollable filter list: `All`, `Factory`, `User`, `Favorites ★`.
  - Category tags: `Bass`, `Kick`, `Snare`, `Percussion`, `Drone`, `Glitch`, `FX`.
  - Author and mood tags.
- **Column 2: Preset Search Results (Width ~210px)**:
  - High-density list displaying preset name and category badge.
  - Audition Icon (`▶`) on hover: clicking (or pressing `Spacebar` while list is focused) triggers an instant drum hit via the lock-free audio thread trigger queue (`triggerAudition`).
  - Arrow up/down navigation for rapid preset browsing.
- **Column 3: Preset Metadata & Playable Macros (Width ~180px)**:
  - Preset title, sound designer name, description notes, and favorite star toggle.
  - 4 interactive Rotary Macro Knobs allowing live parameter shaping directly inside the browser drawer before committing.

### Phase 4: Fullscreen Modulation Matrix Table (`ModMatrixModal`)
- **Modal Component (`ModMatrixModal.h/.cpp`)**:
  - Fullscreen or large centered floating modal (`1000x680px`) styled in the active Studio Theme.
  - Tabular layout powered by `juce::TableListBox`.
- **Table Columns**:
  1. `Source` (LFO 1..4, ENV 1..4, MACRO 1..4, RND 1..4, Velocity, Pitch).
  2. `Target Parameter` (Searchable dropdown / autocomplete).
  3. `Depth` (Bipolar slider `-1.0` to `+1.0` with numeric entry).
  4. `Curve / Skew` (Linear, Exponential, Logarithmic).
  5. `Mute / Solo` (Tactile toggle buttons).
  6. `Actions` (Clear / Unlink button `✕`).
- **Target Filter Search Bar**:
  - Text input to immediately filter rows by target block (e.g. `osc1`, `filter`, `amp`).

### Phase 5: Macro & Performance "Play View" Page
- **Page Layout (`PlayViewPage.h/.cpp`)**:
  - Dedicated page selectable from Chassis Header tabs (`[PLAY]`).
  - Optimized for live performance, stage visibility, and touch/mouse macro sweeps.
- **4 Giant Rotary Macro Dials**:
  - Massive arc meters with large-format JetBrains Mono parameter values and customizable label titles.
  - Audio-reactive pulsing halo synchronized to the synthesizer's output energy.
- **Compact Quick-Access Ribbon**:
  - Panic flush button, Master Volume meter, Audition Trigger button, and Preset Quick-Select dropdown.

## 🛡️ Audio Thread & Memory Safety Invariants
1. **Zero Allocations on UI Toggle**: Toggling between card views, opening the preset browser, or drawing overlay splines must never allocate on or block the audio thread.
2. **Atomic Audition Triggers**: Browser preset auditioning communicates strictly via the existing lock-free `triggerAudition` queue.
3. **Dirty-Rect Repaints Only**: The modulation overlay and animated dock tiles must only invalidate dirty regions, preventing CPU starvation in the host DAW.
