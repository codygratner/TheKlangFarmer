# Docs Inbox

This directory serves as the local repository staging inbox for notes, preset concepts, and sound design ideas synced from the Obsidian Vault (`TheKlangVault/Inbox/`).

- **Local Only (Gitignored)**: All notes in this directory (except this README) are strictly ignored by Git. Raw notes, mobile brain dumps, and scratchpads never leave your machine or leak to GitHub.
- **Workflow**: 
  1. Ideas land here via `tools/sync_obsidian_vault.ps1`.
  2. New Klang City ingests and formalizes approved ideas into `docs/BACKLOG.md` or `docs/draft_plans/`.
  3. Processed notes remain safe in your personal Obsidian Vault.
