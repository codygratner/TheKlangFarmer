# Docs Inbox

This directory serves as the repository staging inbox for notes, preset concepts, and sound design ideas synced from the Obsidian Vault (`TheKlangVault/Inbox/`).

- **Origin**: Notes created on mobile or desktop Obsidian.
- **Workflow**: 
  1. Ideas land here via `tools/sync_obsidian_vault.ps1`.
  2. New Klang City ingests and formalizes approved ideas into `docs/BACKLOG.md` or `docs/draft_plans/`.
  3. Processed notes can be archived into `docs/inbox/archive/`.
