# Creative Lore & Worldbuilding

This directory serves as the local, gitignored repository archive for creative lore, character chronicles, worldbuilding stories, and in-universe mythology of **The Klang Suite** and **New Klang City**.

- **Local Only (Gitignored)**: All markdown chronicles and lore documents in this directory (except this README anchor) are strictly ignored by Git. Creative worldbuilding remains preserved on your local workstation without cluttering public production commits.
- **Obsidian Vault Mirror**: All lore files created here are mirrored into the Obsidian Vault under `TheKlangVault/Lore/`.
- **Registered in Catalog**: Canonical lore chronicles are registered in [`docs/DOCS_CATALOG.json`](file:///c:/Dev/TheKlangSuite/docs/DOCS_CATALOG.json) under `community_and_lore` with `"gitignored": true`.
